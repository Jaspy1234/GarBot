# GarBot
Today was the birth of GarBot. Me and Sabrina came up with the idea tonight, taking inspiration from WALL-E the garbage collector. We wanted to innovate on that ideology to create a robot that can help make our environment cleaner, while increasing convince. Our goals for GarBot is to make it simple to build, highly efficient, and cute!

# Features
- Grabber hands to pick up garbage
- Tank tracks for movement
- Cute screen or design for the face

#Components
- ESP32
- DC motors (x4)
- AA batteries (x4)
- MG996R servo (~5.5 - 11KG)
- Custom made PCB or breadboard
- Capacitor
- Resistors

*IDE used*
- Arduino IDE
